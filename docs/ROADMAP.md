# Development Roadmap

The project is built in 15 development steps. Each step is owned by one team
member, is worked on alone, and ends with reviewed Git commits. Step 15 is
shared.

- **Owner A** — Ratul Islam ([@raHI-79](https://github.com/raHI-79))
